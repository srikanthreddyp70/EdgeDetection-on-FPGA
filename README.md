# FPGA Edge Detection using Verilog

This repository is a starter RTL project for studying hardware-based image
edge detection using **Sobel, Prewitt, and Canny-style processing**.

The project is based on the scope described in the accompanying research
document: comparison of Sobel, Prewitt, and Canny edge detection on an FPGA /
ZedBoard Zynq platform using Verilog and Vivado.

## Repository contents

- `Verilog/sobel_3x3.v` - educational 3x3 Sobel gradient core
- `Verilog/prewitt_3x3.v` - educational 3x3 Prewitt gradient core
- `Verilog/canny_threshold.v` - educational Canny-style final threshold stage
- `Testbench/edge_detection_tb.v` - simple simulation testbench
- `Images/` - supplied input/edge-detection figures
- `Results/` - supplied performance/resource figures

## Important note

The RTL files in this repository are **starter/educational code** and should
not be described as a fully verified reproduction of the research paper until
they have been simulated, synthesized, and validated on the intended FPGA
platform. The Canny file is only a threshold-stage example, not a complete
five-stage Canny accelerator.

## Suggested workflow

1. Open the Verilog files in Vivado.
2. Add the testbench as a simulation source.
3. Run behavioral simulation.
4. Extend the design with image line buffers and a complete streaming
   architecture.
5. Synthesize for the target Zynq/ZedBoard device.
6. Record your own resource and timing results.

## Algorithms

### Sobel
Uses horizontal and vertical 3x3 kernels and an approximation
`|Gx| + |Gy|` for gradient magnitude.

### Prewitt
Uses horizontal and vertical 3x3 kernels and the same hardware-friendly
gradient magnitude approximation.

### Canny
A complete Canny pipeline normally includes Gaussian smoothing, gradient
calculation, non-maximum suppression, double thresholding, and hysteresis.
This repository currently contains only an RTL example of the threshold stage.
