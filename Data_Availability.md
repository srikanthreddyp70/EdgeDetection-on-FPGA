# Data Availability

All of the code used to implement the **Sobel, Prewitt, and Canny edge detection algorithms**, process the **Input Images (Image 1–4)**, and generate the corresponding **Sobel, Prewitt, and Canny edge-detection images**, together with the results reported in **Fig. 3 (Memory Utilization), Fig. 4 (Processing Time), and Fig. 5 (FPGA LUT Usage)**, is available at a GitHub repository [EdgeDetection-on-FPGA](https://github.com/srikanthreddyp70/EdgeDetection-on-FPGA).

The repository contains the Verilog HDL source code, testbench files, input images, Sobel edge images, Prewitt edge images, Canny edge images, and corresponding result figures.
